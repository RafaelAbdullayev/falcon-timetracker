# Учёт рабочего времени (Тестовое задание Falcon AI)

Небольшое веб-приложение для учёта рабочего времени сотрудников. 
Позволяет добавлять сотрудников, запускать и останавливать таймеры задач, а также просматривать отчёты за выбранный период. Данные хранятся в SQLite и сохраняются после перезапуска приложения.

## Стек технологий
- **Backend:** Python 3.15, Flask 3
- **База данных:** SQLite (встроенная библиотека `sqlite3`)
- **Frontend:** HTML, CSS, Vanilla JavaScript (без фреймворков)
- **Тестирование:** pytest
